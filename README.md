# instagram-exporter

Tools for exporting Instagram media and account data.

## Research

- [docs/igexport-reverse-engineering.md](docs/igexport-reverse-engineering.md):
  how igexport.com's downloaders and viewers work. It covers the stories,
  highlights, reels, video, audio and Threads downloaders, the unfollow checker
  and the profile viewer: their API routes, Cloudflare Turnstile gating, input
  parsing, media delivery and in-browser MP3 encoding.
